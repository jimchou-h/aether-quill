# Aether Quill Web

Vue 3 + TypeScript 前端应用

## 技术栈

- Vue 3 (Composition API)
- TypeScript
- Vite
- Vue Router
- Pinia

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 路由

- `/login` - 登录页
- `/projects` - 项目列表
- `/projects/:id/workbench` - 写作工作台
- `/projects/:id/knowledge` - 知识库
- `/projects/:id/settings` - 项目设置
